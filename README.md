# Missió Organigrama – Bombers

Joc per memoritzar l'organigrama que figura a la imatge d'estudi aportada (Decret 12/2023).

## Què inclou

- Esquema buit: toca una casella per revelar o ocultar el nom; filtratge per branca; progrés desat al navegador.
- Imatge original: zoom i desplaçament; l'original manté les anotacions manuscrites.
- Repte de 12 preguntes, parelles, targetes i organigrama desplegable.
- Sense dependències externes: l'original està incrustat a `index.html`.

## GitHub Pages

1. Crea un repositori públic, per exemple `joc-bombers`.
2. Puja `index.html` i `.nojekyll` a l'arrel del repositori (pujar el README és opcional).
3. A **Settings → Pages**, tria **Deploy from a branch**, la branca **main** i **/(root)** i guarda.
4. La URL serà `https://USUARI.github.io/joc-bombers/` quan GitHub confirmi la publicació.

La imatge és una referència històrica d'estudi: no certifica l'estructura administrativa vigent.
